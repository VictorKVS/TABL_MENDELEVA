 TABL_MENDELEVA
Эталонный учебно-корпоративный проект. Доказательство инженерного подхода.
🔷 1. Описание проекта

TABL_MENDELEVA — это демонстрационно-промышленный проект, построенный как эталон современной инженерии программного обеспечения и прикладного искусственного интеллекта.

Проект показывает полный цикл разработки:

проектирование архитектуры,

работа с базами данных,

построение базы знаний,

работа с AI (embeddings, RAG),

REST API,

тестирование,

документация,

промышленный подход к безопасности и качеству.

TABL_MENDELEVA служит корневой платформой, на которой будут строиться:

OSINT-агент

Compliance Checker (ПДн/КИИ/ГОСТ 57580)

Knowledge QA Bot

аналитические инструменты

компоненты MindForge v2.0

🔷 2. Цели проекта

Создать идеальный пример промышленной разработки.

Показать системное мышление и архитектурный подход.

Реализовать базу знаний и векторный поиск.

Подготовить универсальный фундамент для будущих проектов.

Стандартизировать pipeline разработки.

🔷 5. Уровни зрелости проекта (Maturity Model)

Проект развивается не хаотично — а по уровням зрелости, как в промышленной инженерии.

Уровень	Статус	Содержание
L1 — DATA	✔	БД, CRUD, seed, тесты данных
L2 — KNOWLEDGE	⏳	Knowledge Graph, relations
L3 — VECTOR / RAG	⏳	Embeddings, FAISS, поисковые цепочки
L4 — API	⏳	REST API для всех уровней
L5 — BOT	⏳	Telegram бот / web
L6 — ANALYTICS	⏳	Аналитика, фильтры, классификация
L7 — ECOSYSTEM	⏳	Интеграция с MindForge v2.0
