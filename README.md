# 🔬 TABL_MENDELEVA  
Интерактивный учебный проект по Периодической таблице Менделеева.  
Сайт построен на **FastAPI + Jinja2** и содержит информацию обо всех 118 химических элементах.

---

## 🌟 Возможности проекта
- 📚 Просмотр списка всех элементов
- 🔍 Отдельная страница для каждого элемента
- 🧩 Краткие справочные данные
- 🖥 Простая и понятная структура интерфейса
- ⚙️ Возможность лёгкого расширения (поиск, API, LLM-ассистент)

---

## 🚀 Используемые технологии
- **Python 3.10+**
- **FastAPI**
- **Jinja2**
- **Uvicorn**
- **Git + GitHub**

---

## 📁 Структура проекта



TABL_MENDELEVA/
├── main.py # Приложение FastAPI
├── data.py # Данные по 118 элементам
├── templates/ # HTML-шаблоны
│ ├── index.html # Главная страница
│ └── element.html # Страница элемента
└── static/ # CSS, изображения (можно добавлять)

## ▶️ Как запустить проект

### 1. Установить зависимости
```bash
pip install fastapi uvicorn jinja2

2. Запустить локальный сервер
uvicorn main:app --reload

3. Открыть сайт

Открой в браузере:

http://127.0.0.1:8000
